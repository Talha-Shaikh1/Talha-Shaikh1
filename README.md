## 👋 About

I build AI products end to end, alone. **Botaura** is my main one: a multi-tenant RAG chatbot platform for Pakistani SMBs with native Urdu and Hinglish support, from architecture to deployment.

- 🚀 Production SaaS: RAG pipeline, WhatsApp Business API automation, broadcast engine, observability
- 🧠 Stack: Next.js / TypeScript, FastAPI / Python, Postgres + pgvector
- 📈 Right now: WooCommerce plugin + Shopify embedded app for Botaura
- 🎯 Looking for: AI / Cloud Systems Engineering roles and high-scale SaaS work
- 💬 Happy to talk: RAG architectures, WhatsApp Business API / Meta Tech Provider flows, bootstrapping a SaaS solo

| **Backend** | FastAPI · asyncpg · HuggingFace Spaces |
| **Data** | Neon Postgres + pgvector (HNSW) · Cloudflare R2 |
| **AI / Search** | Hybrid retrieval (cosine + BM25) · multilingual embeddings · LLM fallback chain (Grok + OpenRouter) |
| **Channels** | Web widget · WhatsApp Business API · WooCommerce · Shopify |

**Shipped solo:**
- **Multi-tenant core:** strict tenant isolation, sub-second hybrid retrieval
- **WhatsApp engine:** inbound bot, COD order flow, multi-agent team inbox, customer segmentation
- **Growth tools:** broadcast campaigns (Meta Marketing Messages API), click-to-WhatsApp ad attribution, abandoned cart recovery
- **Store integrations:** public Store API powering WooCommerce and Shopify
