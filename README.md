### 🌿 About Me

I design, architect, and deploy production-grade software. Currently building **[Botaura](https://botaura.app)** — an enterprise-grade multi-tenant RAG chatbot platform serving Pakistani SMBs with native Urdu & Hinglish intelligence.

- **Solo Production SaaS**: Architected, developed, and deployed 160+ production endpoints, tenant-isolated vector search, and Meta Tech Provider flows with zero external funding.
- **Full-Stack Depth**: Next.js 16 (App Router/TypeScript) on the frontend, asynchronous FastAPI microservices, and Neon Postgres (pgvector + HNSW) on the data layer.
- **Applied AI & Search**: Hybrid retrieval architectures (BM25 + Cosine Similarity with Dense Embeddings) and intelligent fallback chains across Grok & OpenRouter models.
- **Engineering Rigor**: Actively mastering core CS fundamentals (DSA without AI shortcuts) and modern containerized infrastructure (Docker & Linux).
