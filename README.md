## &nbsp;🏆 Featured Build

<div align="center">
<a href="https://botaura.app">

**[Botaura](https://botaura.app)** is a full multi-tenant RAG chatbot SaaS built to serve Pakistani SMBs, with native Urdu/Hinglish support — from idea to 160+ production routes, built and shipped solo.

| Layer | Architecture & Tech Stack |
|:--|:--|
| **Frontend** | Next.js 16 App Router · TypeScript · Tailwind v4 · Clerk · Drizzle ORM |
| **Backend** | FastAPI · asyncpg · deployed on HuggingFace Spaces |
| **Data & Storage** | Neon Postgres + pgvector (HNSW) · Cloudflare R2 |
| **AI / Search** | Hybrid search (cosine similarity + BM25) · multilingual embeddings · LLM fallback chain (Grok + OpenRouter) |
| **Channels** | Web widget · WhatsApp Business API (Meta Tech Provider model) · WooCommerce · Shopify |
| **Observability** | Full observability stack, admin + client-facing health dashboards, support inbox |

<br/>

**What I built end-to-end:**
- **Core Architecture:** Multi-tenant architecture with strict tenant isolation and sub-second hybrid retrieval.
- **WhatsApp Engine:** Inbound bot, COD order flow, multi-agent team inbox, and customer segmentation.
- **Marketing & Growth:** Broadcast campaigns via Meta's Marketing Messages API, click-to-WhatsApp ad attribution, and abandoned cart recovery.
- **E-Commerce Sync:** Public Store API designed for seamless WooCommerce and Shopify platform integrations.
